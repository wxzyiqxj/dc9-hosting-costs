## 搬瓦工 DC9 是个什么机房

DC9 是搬瓦工编号 USCA_9 的洛杉矶数据中心，物理位置在 CoreSite LA2 机楼。它和 DC6（Digital Realty LAX10）并列，是搬瓦工美西两条 CN2 GIA 旗舰线路，回程同时接入中国电信 CN2 GIA、中国移动 CMIN2 和联通 Premium 三条优质线路，官方对 DC9 的表述是所有中国方向流量都走这三条线路，并称它"offers the best overall network capacity and stability"——整体网络容量和稳定性最好。

## 写在条款里、但会直接影响使用的几条限制

- **限量版 CPU 是按比例限定的。** 官方服务条款里，10G 档限量版 CPU 限定单核 25%、20G 档 50%，常规 CN2 GIA-E 则全天候不限核心。THE PLAN 这类低价限量版跑分好看，但突发负载能力弱于常规版，拿来跑高并发服务会先撞 CPU 墙。
- **超额限速。** 第三方整理的条款口径是 1TB 流量档超出后限速 1Mbps，跑大流量的要留意月度余量。
